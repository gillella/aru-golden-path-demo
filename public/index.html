Aru golden-path demo

This public page is the runnable surface for gillella/aru-golden-path-demo. The factory lives in $ARU_SDLC_HOME; this repo does not vendor playbook skills or lifecycle helpers.

Happy path on this repo's board:

  1. Shape an issue with acceptance criteria and a clear change scope.
  2. Implement in a worktree.
  3. Pass verification and obtain independent review when required by risk.
  4. merge_pr.py --expected-head lands the verified PR.
  5. The consumer deploys an approved artifact and verifies health and rollback.

Walk-through and deployment readiness: see the README in this repository.
